ECOFLY S.L. — Presentación web RETO 01

CÓMO ABRIR:
1. Descomprime ECOFLY_presentacion_web.zip.
2. Abre la carpeta ECOFLY_presentacion_web.
3. Haz doble clic en index.html (Chrome, Edge o Firefox).

CONTROLES:
- Flecha derecha / espacio: siguiente diapositiva.
- Flecha izquierda: diapositiva anterior.
- F: activar o salir de pantalla completa.
- Inicio / Fin: primera o última diapositiva.
- También puedes usar los botones o deslizar en móvil.

La presentación funciona sin conexión a Internet. Mantén la carpeta assets junto a index.html.
